# EVEDEX — Crypto Exchange: Forex, Indexes & Metals

EVEDEX is a hybrid, self-custodial crypto derivatives exchange built on Arbitrum Layer 3, offering perpetual futures, P2P, and copy trading. It exposes a REST API (Auth, Exchange, and Market Data services), a Centrifugo WebSocket real-time API, OpenAPI/Swagger contracts, an official Node.js/TypeScript SDK, and an llms.txt agent-native surface.
